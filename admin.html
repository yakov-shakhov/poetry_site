Управление сайтом

Админка доступна только из песочницы — по адресу yakov-shakhov.github.io/poetry_site/admin.html.

Вход

Нужен GitHub-токен (fine-grained) с правами: poetry_site — Contents: Read and write; poetry_site_prod — Actions: Read and write. Токен хранится только в этом браузере.
