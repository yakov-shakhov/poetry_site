РЕКОМЕНДАЦИИ ПО РАСШИРЕНИЮ ПРОЕКТА
===================================

Список упорядочен от простого к сложному. Первые пункты можно
сделать за один вечер, последние — по мере роста проекта.


1. КОНТЕНТ И СТРУКТУРА
----------------------
* Разделы-подборки: «Избранное», циклы и книги стихов
  (добавьте в данные поле "collection" и вкладку на главной).
* Комментарии автора к стихам: история создания, контекст
  (поле "note" в data/poems.js + блок под текстом).
* Аудиозаписи: авторское чтение стихов. Хостинг аудио —
  на GitHub (до 100 МБ на файл) или в подкаст-платформе;
  плеер — обычный тег <audio>.
* Фотогалерея: поездки, встречи, места из стихов
  (Елец, Петербург, Коктебель…).
* Страница «Переводы» отдельным разделом — у вас их уже много.
* RSS-лента новых стихов (генерируется тем же скриптом, что и poems.js).

2. УДОБСТВО НАПОЛНЕНИЯ
----------------------
* Автоматическая публикация: настроить GitHub Actions, который
  раз в неделю запускает scripts/import_stihi.py и коммитит новые
  стихи со Стихи.ру — сайт будет обновляться сам.
* Замена ручного экспорта poems.js на CMS:
  - Decap CMS (бесплатно, работает поверх GitHub) —
    редактирование в браузере с кнопкой «Опубликовать»;
  - либо простой бот в Telegram: отправил стих боту — он сделал
    commit через GitHub API.
* Кнопка «Черновики» в admin.html: публиковать не сразу,
  а после проверки.

3. ЧИТАТЕЛИ И ОБРАТНАЯ СВЯЗЬ
----------------------------
* Комментарии: виджет ВКонтакте (логично — у вас там аудитория)
  или giscus (комментарии через GitHub Discussions, без рекламы).
* Кнопка «Поделиться» для WhatsApp/Telegram (библиотека ShareJS
  или просто ссылки wa.me/?text=...).
* Форма обратной связи через бесплатный сервис Formspree/Formsubmit.
* Рассылка «новые стихи на почту» — Buttondown или Listmonk.

4. ПРОДВИЖЕНИЕ
--------------
* Мета-теги Open Graph (картинка + название при отправке ссылки
  в соцсети) и JSON-LD разметка «Произведение» — лучше вид в
  поиске и мессенджерах.
* sitemap.xml и robots.txt, добавить сайт в Google Search Console
  и Яндекс.Вебмастер.
* Красивые короткие ссылки вида /p/7021 вместо /#poem/... —
  настройка 404.html-редиректа (для GitHub Pages).
* Яндекс.Метрика или Statcounter — статистика посещений.

5. ТЕХНИЧЕСКОЕ РАЗВИТИЕ
-----------------------
* Тёмная тема (кнопка-переключатель, запоминание выбора).
* Случайный стих на главной: «Удиви меня».
* Полный текстовый поиск переехал бы на lunr.js или MiniSearch —
  мгновенный поиск прямо при наборе.
* Прогрессивное веб-приложение (PWA): чтение офлайн, иконка
  на телефоне.
* Свой домен (например, shakhov.poetry) — GitHub Pages
  поддерживает кастомные домены бесплатно.
* Если стихов станет больше 1000 или понадобится регистрация
  читателей — перейти на статический генератор (Astro, Eleventy)
  или лёгкий бэкенд (например, Cloudflare Pages Functions).
