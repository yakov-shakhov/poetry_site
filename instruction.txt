ИНСТРУКЦИЯ ПО САЙТУ «ЯКОВ ШАХОВ — СТИХИ»
==========================================

Сайт — статический: все стихотворения хранятся в файле data/poems.js,
страницы (index.html, admin.html) читают его прямо в браузере.
Хостинг — GitHub Pages: сайт доступен по адресу
https://<ваш-логин>.github.io/poetry_site/


1. КАК ПОЛЬЗОВАТЬСЯ САЙТОМ (ЧИТАТЕЛЮ)
-------------------------------------
* Главная страница — сведения об авторе и полный список произведений
  (сначала новые).
* Строка «Поиск» ищет по названиям и тексту стихов.
* Выпадающий список «Все рубрики» фильтрует по тематике
  (философская, городская, любовная лирика и т. д.).
* Клик по названию открывает стихотворение; внизу страницы —
  ссылки «предыдущее / следующее», а также ссылка на оригинал
  на Стихи.ру.
* Прямые ссылки на стихи имеют вид
  https://<ваш-логин>.github.io/poetry_site/#poem/<код> —
  ими можно делиться.


2. КАК ДОБАВИТЬ СТИХОТВОРЕНИЕ (АВТОРУ)
--------------------------------------
Способ А. Через страницу управления (проще всего)
  1. Откройте admin.html на сайте (пункт меню «Добавить стих»).
  2. Заполните название, рубрику, дату (ГГГГ-ММ-ДД) и текст.
  3. Нажмите «Добавить стих» — черновик сохранится в браузере
     и сразу появится на сайте (пока только у вас).
  4. Чтобы опубликовать для всех: нажмите «Скачать poems.js»,
     полученным файлом замените data/poems.js в папке проекта,
     затем выполните публикацию (см. раздел 3).

  В той же панели можно править существующие стихи («Правка»)
  и удалять их («Удалить»). Кнопка «Сбросить локальные изменения»
  возвращает версию из data/poems.js.

Способ Б. Автоматический импорт со Стихи.ру
  Требуется Python 3.
  * Импортировать одно стихотворение:
      python3 scripts/import_stihi.py https://stihi.ru/2021/02/14/7021
  * Импортировать ВСЕ произведения автора, которых ещё нет на сайте:
      python3 scripts/import_stihi.py --all https://stihi.ru/avtor/yakovshakhov
  Скрипт сам допишет новые стихи в data/poems.js. Останется
  только опубликовать изменения (раздел 3).

Способ В. Вручную
  Откройте data/poems.js в любом текстовом редакторе и добавьте
  в массив объект вида:
  {
   "id": "unikalnyi-kod",
   "title": "Название",
   "genre": "рубрика",
   "date": "19.10.2026",
   "text": "строка 1\nстрока 2"
  }
  Важно: id должен быть уникальным, внутри text перенос строки — \n,
  кавычки внутри текста экранируйте: \"


3. КАК ОПУБЛИКОВАТЬ ИЗМЕНЕНИЯ
-----------------------------
Вариант 1. Через сайт GitHub (без командной строки)
  1. Откройте https://github.com/<ваш-логин>/poetry_site
  2. Файл data/poems.js → кнопка карандаша (Edit).
  3. Вставьте содержимое нового файла (или вставьте новый стих
     вручную, см. способ В).
  4. Кнопка «Commit changes». Через минуту-две сайт обновится сам.

Вариант 2. Через командную строку
      git add data/poems.js
      git commit -m "Добавил стих <название>"
      git push
  Сайт обновится автоматически через 1–2 минуты.


4. КАК ИЗМЕНИТЬ СВЕДЕНИЯ ОБ АВТОРЕ
----------------------------------
Отредактируйте файл data/author.js (имя, фото, текст «О себе»,
ссылки) и опубликуйте, как в разделе 3. Фото лежит в assets/photo.jpg.


5. ЛОКАЛЬНЫЙ ПРОСМОТР
---------------------
Из папки проекта:
      python3 -m http.server 8000
и откройте в браузере http://localhost:8000


6. ЧАСТЫЕ ВОПРОСЫ
-----------------
* «Добавил стих, а у других его нет» — вы сохранили его только в
  своём браузере. Выполните шаги 2-А.4 и раздел 3.
* «Стих в списке есть, страница не открывается» — проверьте,
  что id уникален и не содержит пробелов и кириллицы.
* «После правки poems.js сайт сломался» — проверьте файл на
  https://jsonlint.com (уберите префикс «window.POEMS = » и
  «;» в конце) или нажмите «Сбросить локальные изменения» в admin.html.
