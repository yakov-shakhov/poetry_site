ИНСТРУКЦИЯ ПО САЙТУ «ЯКОВ ШАХОВ — СТИХИ»
==========================================

Сайт — статический: все данные хранятся в файлах data/*.js
(poems.js — стихи, author.js — автор, audio.js — аудио, video.js — видео).
Хостинг — GitHub Pages:
  песочница: https://yakov-shakhov.github.io/poetry_site/
  прод:      https://yakovshakhov.ru/  (репозиторий poetry_site_prod)


1. КАК ПОЛЬЗОВАТЬСЯ САЙТОМ (ЧИТАТЕЛЮ)
-------------------------------------
* Главная страница — сведения об авторе и полный список произведений
  (сначала новые).
* Строка «Поиск» ищет по названиям и тексту стихов.
* Чипсы рубрик фильтруют по тематике (философская, городская,
  любовная лирика и т. д.).
* Клик по названию открывает стихотворение.
* Прямые ссылки на стихи: https://yakovshakhov.ru/#poem/<код>,
  на аудио: https://yakovshakhov.ru/#audio?play=<id>.

Страницы каждого стиха есть и в «человеческом» виде —
https://yakovshakhov.ru/poem/<код>.html (для поисковиков и соцсетей;
генерируются автоматически, см. раздел 4).


2. КАК ВЕСТИ САЙТ (АВТОРУ): ВЕБ-АДМИНКА
---------------------------------------
Адрес: https://yakov-shakhov.github.io/poetry_site/admin.html
(только в песочнице; на проде админки нет).

Вход: GitHub-токен (fine-grained PAT). Права токена:
  * poetry_site      — Contents: Read and write
  * poetry_site_prod — Actions: Read and write (для кнопки «В прод»)
Выпускается на https://github.com/settings/personal-access-tokens
на 90 дней; после истечения выпустить новый.
Галка «Запомнить» хранит токен в браузере (localStorage).

Возможности:
  * Стихи — добавить / править / удалить (удаление блокируется,
    если стих связан с аудио или видео — сначала уберите связь).
  * Аудио — добавить (mp3 кладётся в assets/audio/ автоматически) /
    править / удалить (вместе с mp3).
  * Видео — добавить по ссылке vkvideo (id и embed считаются сами),
    обложка (JPG) кладётся в assets/video-covers/; правка, удаление.
  * Биография — имя, строка о себе, фото, ссылки.
  * В прод — кнопка «Опубликовать в прод»: запускает workflow
    sync-from-sandbox в прод-репозитории. Он переносит контент
    с учётом особенностей прода (не трогает robots.txt, CNAME,
    не тащит noindex) и сам перегенерирует страницы стихов.

Порядок работы: правка в админке → проверка на песочнице
(данные обновляются сразу, страницы стихов — через 1–2 минуты:
их перегенерирует workflow regen-pages) → «В прод» → прод через
1–3 минуты.

Если «не работает новое» после публикации — это кэш Pages (живёт
до 10 минут): инкогнито или Ctrl+F5.

При правке страницы стихов сразу не появились — загляните в
https://github.com/yakov-shakhov/poetry_site/actions: workflow
regen-pages должен быть зелёным.


3. КАК ВЕСТИ САЙТ БЕЗ АДМИНКИ (ЗАПАСНОЙ ПУТЬ)
---------------------------------------------
* Файлы data/*.js — обычный JS: массив JSON-объектов после
  «window.POEMS = ». Правится любым редактором, коммитится в git.
  Формат стиха: { "id": "уникальный-код", "title", "genre",
  "date": "ДД.ММ.ГГГГ ЧЧ:ММ", "text": "строка 1\nстрока 2" }.
* Импорт со Стихи.ру: python3 scripts/import_stihi.py <ссылка>
  (--all — импортировать всё новое с страницы автора).
* Регенерация страниц стихов и sitemap: python3 scripts/generate_pages.py
  (в песочнице происходит автоматически при пуше в data/).
* Проверка целостности данных: node scripts/check_data.js
* Перенос в прод без кнопки: клон poetry_site_prod, скопировать
  data/, assets/, index.html (убрав строку noindex!), scripts/,
  перегенерировать poem/ и sitemap.xml, НЕ трогать robots.txt
  и CNAME. (Кнопка «В прод» делает ровно это.)


4. КАК УСТРОЕН САЙТ (СЛУЖЕБНОЕ)
-------------------------------
* Задача взять файл по https://yakovshakhov.ru/data/poems.js —
  там данные прода, у песочницы свои: .../poetry_site/data/poems.js.
* index.html — SPA (hash-роутинг #poem/<id>). generate_pages.py
  делает по статической странице на стих (poem/<id>.html) +
  sitemap.xml; шаблон страницы — index.html.
* scripts/check_data.js гоняется pre-push-хуком (scripts/hooks).
* Telegram-бот (@poem_editor_bot) отключён 2026-11-10; папка bot/
  удалена. systemd-сервис poetry-bot остановлен.
