ИНСТРУКЦИЯ ПО TELEGRAM-БОТУ — АДМИНКЕ САЙТА «ЯКОВ ШАХОВ — СТИХИ»
=================================================================

Телеграм-бот (папка bot/) позволяет добавлять, редактировать и удалять
стихотворения, а также менять сведения об авторе — прямо из Telegram.
Каждое изменение бот сохраняет в data/poems.js или data/author.js,
делает git-коммит и отправляет его на GitHub, после чего сайт
(GitHub Pages) обновляется автоматически через 1–2 минуты.

ТРЕБОВАНИЯ
----------
* Python 3.10+ и pip на компьютере, где запущен бот.
* Клон репозитория poetry_site с настроенным доступом на push
  (если пушите по https — выполните один раз «gh auth login» либо
  используйте SSH-remote; бот делает обычные «git pull --rebase» и «git push»).

1. ПОДКЛЮЧЕНИЕ БОТА (ОДИН РАЗ)
------------------------------
1.1. В Telegram напишите @BotFather → команда /newbot → задайте имя
     и username. BotFather выдаст токен вида 123456789:AA... — он
     понадобится для запуска.
1.2. Узнайте свой Telegram ID (например, у бота @userinfobot) —
     чтобы вписать его в список администраторов.

2. ЗАПУСК БОТА
--------------
Из папки репозитория poetry_site:

    cd bot
    python3 -m venv .venv
    source .venv/bin/activate        # Windows: .venv\Scripts\activate
    pip install -r requirements.txt

    export BOT_TOKEN="токен_от_BotFather"
    export ADMIN_IDS="ваш_telegram_id"        # можно несколько через запятую
    python3 bot.py

Удобно записать переменные в файл bot/.env (пример — bot/.env.example)
и запускать:  set -a; source .env; set +a; python3 bot.py

Если ваш ID заранее не вписан, можно выдать доступ по паролю:
    export ADMIN_PASSWORD="секретный-пароль"
и первый вход в Telegram:  /start секретный-пароль
ID сохранится в bot/admins.json (файл не публикуется, он в .gitignore).

Переменные окружения (все в .env.example):
    BOT_TOKEN        токен бота (обязателен)
    ADMIN_IDS        Telegram ID администраторов через запятую
    ADMIN_PASSWORD   пароль первого входа (альтернатива ADMIN_IDS)
    AUTO_PUSH        1 — после каждого изменения делать git push
                     (по умолчанию), 0 — только локальные коммиты
    BOT_GIT_NAME,    имя/почта для коммитов бота
    BOT_GIT_EMAIL    (по умолчанию «poetry-site-bot»)
    REPO_DIR         путь к репозиторию сайта, если бот запускается
                     не из его клона (по умолчанию — папка выше bot/)

3. КОМАНДЫ БОТА
---------------
/add     — добавить стихотворение (мастер из 5 шагов)
/edit    — отредактировать стих: название, рубрика, дата, текст, ссылка
/delete  — удалить стих (с подтверждением)
/list    — список всех стихов (листается кнопками ⬅️ ➡️)
/find    — поиск по названиям и тексту: /find <фрагмент>
/author  — редактировать имя, «О себе» и ссылки автора
/id      — показать ваш Telegram ID
/cancel  — отменить текущее действие
/help    — справка

4. КАК ДОБАВИТЬ СТИХ (/add)
---------------------------
1. Пришлите название (или /skip).
2. Выберите рубрику кнопкой или пришлите свою.
3. Дата в формате ДД.ММ.ГГГГ (или /skip — подставится текущая).
4. Ссылка на источник (stihi.ru) или /skip.
5. Текст стиха — можно несколькими сообщениями; когда закончите,
   отправьте /done.
6. Проверьте черновик и нажмите «✅ Опубликовать».
Стих встанет первым в списке на сайте (там сначала новые).

5. КАК ИЗМЕНИТЬ СТИХ (/edit) И УДАЛИТЬ (/delete)
------------------------------------------------
/edit — выберите стих кнопкой (или пришлите слово для поиска),
затем поле: Название / Рубрика / Дата / Текст / Ссылка.
Новое значение можно присылать так же по частям с /done в конце.
«✅ Готово» — завершить правку. Каждое поле публикуется отдельным
коммитом сразу после сохранения.

/delete — выберите стих и подтвердите удаление.

6. КАК ИЗМЕНИТЬ СВЕДЕНИЯ ОБ АВТОРЕ (/author)
--------------------------------------------
Кнопки: Имя, «О себе», ссылки (stihi, vk). Пришлите новое значение —
сохранится в data/author.js и опубликуется.

7. КАК ОСТАНОВИТЬ / ЗАПУСТИТЬ НАПОСТОЯННО
-----------------------------------------
Остановить: Ctrl+C в окне запуска бота.
Автозапуск на Linux — через systemd-сервис, например:

    [Unit]
    Description=Poetry site Telegram bot
    After=network.target

    [Service]
    WorkingDirectory=/путь/к/poetry_site
    EnvironmentFile=/путь/к/poetry_site/bot/.env
    ExecStart=/путь/к/poetry_site/bot/.venv/bin/python /путь/к/poetry_site/bot/bot.py
    Restart=always

    [Install]
    WantedBy=multi-user.target

8. ПРОВЕРКА, ЧТО БОТ НЕ СЛОМАЕТ САЙТ
------------------------------------
python3 bot/test_smoke.py — прогоняет сценарии добавления, правки,
удаления и правки автора на временной копии репозитория.
Файл data/poems.js бот пишет в том же формате, что и на сайте
(проверено: перезапись без изменений даёт байт-в-байт тот же файл).

9. ЧАСТЫЕ ВОПРОСЫ
-----------------
* «Unauthorized» / 401 при запуске — неверный BOT_TOKEN.
* «Доступ только для автора» — ваш ID не в ADMIN_IDS. Пришлите /id,
  добавьте ID в ADMIN_IDS и перезапустите бота, либо войдите
  по /start <пароль>.
* «push не удался» — у клона нет прав на запись. Выполните git push
  вручную (бот сообщит об этом) и настройте доступ.
* Изменил стих на компьютере вручную, а бот перезаписал — бот перед
  каждым изменением заново читает файлы, поэтому правьте либо там,
  либо там, но не одновременно; git-история сохранит всё.
* Токен бота скомпрометирован — @BotFather → /revoke, выпустите новый
  и перезапустите бота.
